使用指南

从怎么问问题、怎么选牌阵，到塔罗牌本身的秘密——以及这个网站是怎么被做出来的。

How To

一次占卜的完整流程

① 先把问题问对

塔罗擅长回答"现状、趋势与选择"，不擅长回答精确的数字、日期或他人的隐私心思。

  • 把问题聚焦到"现在"与"我"，例如"我在这段关系中的状态如何"。
  • 避免问"他会不会爱我"这类你无法控制他人心意的问题。
  • 同一个问题连续问三次会削弱牌意，换个角度问更好。

② 按问题的复杂度选牌阵

  • 只要一个方向：一张牌展开法（1 张）
  • 一个二选一决定：是否抉择展开法（1 张）
  • 看事情的发展：过去现在未来（3 张）
  • 向内看自己：了解自己展开法（3 张）
  • 看整件事的结构：解决方案（5 张）／金字塔（7 张）
  • 看关系与全景：新关系（5 张）／元素五芒星（5 张）／安娜金关系（10 张）／凯尔特十字（10 张）

③ 让心静下来再洗牌

洗牌不是玄学步骤，而是把注意力从"急于得到答案"切换到"认真对待这个问题"的过程。

  • 在心中默念你的问题，然后点击"开始洗牌"。
  • 牌会正面朝下摊在牌桌上，位置顺序就是牌阵的结构。
  • 逐张点击翻开——翻牌的动作由你亲手完成。

④ 读懂你的牌

解读由四部分组成：

  • 逐张解读：该位置在牌阵中的意义 + 这张牌的牌义。
  • 能量分析：火/水/风/土 哪种元素占优，它代表当下什么在主导。
  • 综合结论：从第一张牌到最后一张牌的走向。
  • 行动建议：三条可以今天就执行的建议。

Knowledge

塔罗基础知识

牌组结构：22 + 56

大阿卡纳 22 张是"主牌"，以人物与情景为原型，讲的是生命旅程的阶段与母题：愚人到世界，构成一个完整的循环。

小阿卡纳 56 张是"副牌"，按权杖（火）、圣杯（水）、宝剑（风）、星币（土）四组展开，每组 14 张，讲述日常中的行动、情感、思考与物质。

本站的基础占卜只用 22 张大阿卡纳，因为它们回答的是"性质与方向"；深度占卜启用全部 78 张，因为细节与步骤藏在小牌里。

四种元素

  • 火 · 权杖：行动、热情、创造、冲劲。火多时需要的是"开始做"。
  • 水 · 圣杯：情感、关系、直觉。水多时需要的是"感受与沟通"。
  • 风 · 宝剑：思想、言语、冲突、真相。风多时需要的是"把话说清楚"。
  • 土 · 星币：金钱、身体、工作、现实。土多时需要的是"落实与耐心"。

解读页的"能量分析"会统计你这次抽到的四种元素比例，并指出哪一种在主导。

正位与逆位

牌抽出来后，约四成概率会以逆位出现（本站设定为 42%）。

正位表示该能量顺畅地表达；逆位不必然是"坏"，而是该能量受阻、过度或转向内部——比如"力量"逆位不是软弱，而是内在力量尚未被驯服。

解读时，逆位会与所在位置的含义结合，而不是简单地判为凶吉。

关于占卜的边界

塔罗是一套象征系统与自我投射工具，它擅长帮你把模糊的困扰说清楚。

它不预测彩票号码，不替代医疗、法律与专业意见，也不负责替别人做决定。

本站所有结果由随机牌组与固定牌义生成，仅供自我思考与娱乐参考。

Structure

本站页面结构

共 6 个网页，页面之间全部使用相对路径相互跳转，可直接双击 index.html 离线打开。

页面 相对路径 内容
主页index.html站点入口、两种占卜模式介绍、十种牌阵一览
基础占卜basic.html22 张大阿卡纳，4 种牌阵的完整占卜流程
深度占卜deep.html完整 78 张，6 种牌阵的完整占卜流程
牌阵图鉴spreads.html十种牌阵的位置含义与备选问题
塔罗牌图鉴cards.html78 张牌面、正逆位释义与元素属性
使用指南guide.html占卜指引、塔罗基础知识、页面结构说明

技术实现

  • 纯静态页面：HTML + CSS + 原生 JavaScript，无框架、无外部依赖，离线可用。
  • 全部 78 张卡面由 SVG 程序化绘制（js/deck.js），每张牌的纹章由牌号哈希生成，几何图案互不相同。
  • 洗牌使用 crypto.getRandomValues() 实现无偏随机；逆位出现概率设为 42%。
  • 牌阵布局使用 CSS Grid 的 grid-area 精确定位，十种牌阵各有专属布局类。
  • 翻牌效果使用 CSS 3D 变换（preserve-3d + rotateY），无图片素材。

文件结构

  • index.html · basic.html · deep.html
  • spreads.html · cards.html · guide.html
  • css/style.css — 深色神秘学主题与全部牌阵布局
  • js/cards-major.js — 22 张大阿卡纳牌义
  • js/cards-minor.js — 56 张小阿卡纳牌义
  • js/spreads.js — 10 种牌阵与问题库
  • js/deck.js — 洗牌、抽牌与 SVG 卡面生成
  • js/divination.js — 占卜流程与解读生成
  • images/ — 自制插画素材
